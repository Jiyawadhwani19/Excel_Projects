# 📊 Student Performance Analysis (Excel)

## Overview

This project is a Microsoft Excel-based Student Performance Analysis worksheet created to practice essential and intermediate Excel concepts. It demonstrates random data generation, logical functions, grading automation, and conditional formatting using a dataset of student exam results.

---

## Objective

The objective of this project is to:

- Generate sample marks using the `RANDBETWEEN()` function.
- Perform score and percentage calculations.
- Analyze student performance using logical functions.
- Assign grades automatically with Nested IF.
- Visualize results using Conditional Formatting.

---

## Dataset

The dataset contains records for **10 students** with marks in **5 subjects**:

- Mathematics
- Science
- English
- History
- Computer

Additional calculated columns include:

- Total Score
- Percentage
- Overall Status
- Retest Required
- Final Grade

## Tasks Performed

### 🔹 Data Generation

- Generated random marks between **15 and 95** using `RANDBETWEEN()`.
- Converted formulas into static values using **Paste Special → Values** to prevent marks from changing.

### 🔹 Calculations

- Calculated Total Score.
- Calculated Percentage.

### 🔹 Logical Analysis

- Determined Overall Status using **AND()**.
- Identified Retest Requirement using **OR()**.
- Assigned Final Grades using **Nested IF()**.

### 🔹 Conditional Formatting

Applied Conditional Formatting to:

- Highlight failed subject marks (below 35).
- Highlight Outstanding ("O") grades.
- Display Data Bars for Percentage.
