# 📈 Student Management Dashboard (Excel)

## Overview

This project is a Microsoft Excel-based Student Management Dashboard created using a sample student dataset. It demonstrates data analysis, logical functions, filtering, sorting, conditional formatting, data validation, duplicate handling, and dashboard creation.

---

## Objective

The objective of this project is to analyze student records and build an interactive dashboard that summarizes important academic and administrative information.

---

## Dataset

The dataset contains student records including:

- Student ID
- Student Name
- Age
- Course
- City
- Marks
- Attendance
- Fees Paid Status

The project also includes calculated columns for:

- Exam Eligibility
- Fee Reminder
- Hostel Eligibility
- Adult Status
- Placement Training Eligibility
- Student Category
- Priority Level
- Counselling Requirement

## Tasks Performed

### 🔹 Data Analysis

- Counted students based on different conditions.
- Calculated attendance statistics.
- Calculated fee payment statistics.
- Identified students by city, course, and age.

### 🔹 Logical Functions

Created automated columns for:

- Exam Eligibility
- Fee Reminder
- Hostel Eligibility
- Adult Status
- Placement Training
- Student Category
- Priority Level
- Counselling Requirement

### 🔹 Data Management

- Applied Sorting.
- Applied Filtering.
- Created Dropdown Lists using Data Validation.
- Removed Duplicate Records.

### 🔹 Dashboard

Created a dashboard displaying:

- Total Students
- Total Local Students
- Total Hostel Candidates
- Total Fees Paid
- Total Fees Pending
- Students Eligible for Exam
- Students Not Eligible
- Average Attendance
- Students Above 22 Years
- Student Distribution by City (Chart)
